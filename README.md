# Plust (Player-Rust)

**A mutliplatform mp4 video player**

I am building Plust to learn more about how mp4 videos are streamed and rendered in real time onto screenes.
I chose rust for the core cause its cool and I like cool stuff :).
I wanted to make it mutliplatform because it sounded fun!
